PARCHÍS DELUXE

- 2 a 4 jugadores.
- Si hay 2 jugadores, cada uno controla dos colores:
  Jugador 1: rojo + verde
  Jugador 2: azul + amarillo.
- 4 fichas por color.
- Dado, turnos, capturas, seguros, meta y puntuación.
- Preparado como módulo independiente para integrarlo en AppJuegosOnline.

INSTALACIÓN
1. Copia esta carpeta dentro de JUEGOS/
2. Ejecuta dentro de ella:
   python INSTALAR_PARCHIS.py
3. Añade en juegos.html un botón POST a:
   /crear_sala/parchis
